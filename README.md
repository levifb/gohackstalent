# gohackstalent

Projeto do GoHacks Talent 2026 (Gogroup, 07/11/2026).

## Estrutura

| Pasta | Conteúdo |
| --- | --- |
| `prompts/` | Prompts e contexto do dia (`claude_contexto_hackathon.md`, `prompt_escolher_desafio.md`, `prompt_criar_skills.md`, `prompts_do_dia.md`, `agente_avaliador.md`) |

| `dados/` | Bases CSV fictícias dos 3 desafios (`atendimento/`, `pagamentos/`, `transportes/`) e os zips originais em `dados/raw/`. **Fora do git**: os dados são confidenciais e o repositório será público |
